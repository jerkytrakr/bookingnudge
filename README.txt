BookingNudge — Installable Web App (PWA)

CONTENTS
index.html — the application
manifest.webmanifest — app installation metadata
sw.js — offline cache
icon-192.png and icon-512.png — app icons

HOW TO USE
1. Upload ALL five files together to a HTTPS web host (for example Netlify Drop, Cloudflare Pages, or GitHub Pages).
2. Open the resulting HTTPS website on your Android or iPhone.
3. Android Chrome: browser menu > Add to Home screen / Install app.
4. iPhone Safari: Share > Add to Home Screen.
5. Enter customer details and press Open phone's SMS app. Review and send the text yourself.

The app does not send messages automatically and does not schedule notifications.
No customer list or booking diary. Data entered into fields is not uploaded by this app.
Your SMS app/carrier may charge for messages.
Some browser/phone combinations may not prefill SMS body; use Copy message as fallback.

A downloaded HTML file can be opened for a quick test but cannot normally be installed as a full offline PWA until hosted on HTTPS.
